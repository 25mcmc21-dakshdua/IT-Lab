# Weather App - React AJAX Assignment

React application that fetches and displays real-time weather data using AJAX.

## Features
- Current weather (temperature, humidity, conditions)
- Search by city name
- 5-day forecast
- Error handling
- Loading states

## Setup Instructions

1. Get API key from OpenWeatherMap (https://openweathermap.org/api)
2. Replace 'YOUR_API_KEY' in src/App.js with your actual key
3. Install dependencies: `npm install`
4. Run the app: `npm start`
5. Open http://localhost:3000

## Technologies
- React (useState, useEffect)
- Fetch API
- OpenWeatherMap API
